Parametrically generated by `taplab forge`; every manifest.yml records the
complete parameter set and seed, so each instance is reproducible from its
manifest alone. Bundled examples: diamond (asymmetric two-route), braess /
braess_no_diag (the paradox reproduces exactly: 82.25 vs 66.00 minutes at
equilibrium), grid10_corner_s1 (Manhattan corner-to-corner), grid12_rich_s7
(route-rich: corridors + barrier + Braess diagonal + perturbed costs — the
controlled latent-atom testbed).
